# 03 Plans

Plans **not yet implemented**. One file per work item, numbered.

When the plan's PR is merged into `main`, closure is another commit on `main`:
update the living architecture and move this file to
`90-99 Archive/91 implemented plans/`. The number doesn't change. Then the
plan branch is deleted, both locally and on remote, and the local `main`
follows the remote. The full workflow for any plan is in
[`../04 Playbooks/fechar-plano.md`](../04%20Playbooks/fechar-plano.md).
